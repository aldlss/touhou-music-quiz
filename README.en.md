# Touhou Music Quiz — Endless Edition

[简体中文](./README.md) | English

[Play online](https://quiz.touhou.page/en)

## About

This is a music quiz built with [Next.js](https://nextjs.org/) that tests how well you know original music from the Touhou Project.

Rather than duplicating the [THBWiki version](https://cd.thwiki.cc/quiz), this edition takes a slightly different approach:

1. There is no fixed number of questions; you can end the quiz whenever you like.
2. Each music clip starts at a completely random position.
3. You have more freedom to choose which tracks are included in the quiz.
4. More tracks are available.

## How to Play

Instructions are available in the quiz itself and in this [Bilibili video](https://www.bilibili.com/video/BV1Nz42167QC/).

Some Touhou tracks have multiple closely related versions, so only one version is included in the quiz. In general, preference is given to the version that appeared first and to versions from the official games.

See the [complete track list and excluded tracks](./docs/data/README.md) for details. The track selection was put together rather quickly, so reports of omissions or questionable choices are welcome.
